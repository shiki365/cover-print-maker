# 表紙入稿メーカー

同人誌の表紙の絵（表1・表4、または見開き1枚）から、表1・背・表4 を1枚につないだ入稿用の表紙データ（塗り足しつき・CMYK の PDF）を、ブラウザだけで作るツール。

**公開サイト（予定）: https://shiki365.github.io/cover-print-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要）。

## できること

- **印刷所（22社）** — 栄光・オレンジ工房・金沢印刷・関西美術印刷・グラフィック・コーシン出版・サンライズ・しまや出版・STARBOOKS・大陽出版・ちょ古っ都製本工房・ツクヨミ・トム出版・西村謄写堂印刷・日光企画・ねこのしっぽ・PICO・ブロス・ホープツーワン・POPLS・丸正インキ・緑陽社と、数値を入力する「そのほか」。塗り足し・安全域・解像度・インク総量は各社の原稿作成の案内から取った。案内に数値が無い項目は、このツールの標準値（安全域 5mm・インク総量 300%）と画面に出す。RGB で入稿する商品や PP 加工の注意など、印刷所ごとの注意も出す
- **どの印刷所がいいか分からないとき** — 「本」のタブから、別のサイト「同人誌の印刷所さがし」（`https://shiki365.github.io/doujin-printer-finder/`）へ。部数・予算・入稿や納品の条件で絞り込み、値段の目安の安い順に並べる。そこの「この印刷所で表紙を作る」から、このツールを `?printer=<id>&format=<判型>&pages=<本文ページ>` で開くと、その印刷所・判型・ページ数にして「本」のタブを開く（引数は読んだあとアドレスから消す）
- **背幅の計算** — 印刷所ごとの式・計算フォーム・早見表（ページ数か枚数か、表紙の紙を足すか、丸め方は社ごとに違う）。計算フォームがある印刷所は、そのフォームと同じ計算と丸めにした。式を公開していない印刷所（STARBOOKS・ツクヨミ・西村謄写堂印刷）は、印刷所で確かめた値を入力する。注文画面の背幅で上書きできる
- **描く人に渡すガイド画像** — 仕上がり線・塗り足し・安全域・背を描いた透明な PNG（見開き／表1だけ／表4だけ）
- **入稿用の PDF** — 絵を塗り足しまで覆うように拡大して並べ、背を色で埋め、ICC プロファイルで CMYK にし、インク総量を抑えて、TrimBox つきの1ページの PDF にする
- **判型** — B5・A5・A4・B6・文庫（A6）・新書・横長（A5・B5・A4。短い辺で綴じる）・正方形（182mm・148mm）と、大きさを入力。新書は印刷所ごとに大きさが違うので、案内に大きさがある印刷所（トム出版・金沢印刷 105×173、ブロス・ホープツーワン 106×173、サンライズ 110×173、大陽出版 110×175、STARBOOKS 105×175、ねこのしっぽ 112×176）はその大きさにする。無い印刷所では 105×173 で作り、「確認」で大きさを確かめるよう出す
- **右綴じ**（縦書きの本。表1 が左）と左綴じ
- **権利表記は入れない** — 載せる場所・大きさ・文は元の作品のガイドラインで決まるので、絵に描き込んでもらう（2026-11-07 に機能を外した）。「絵」のタブに、ガイドラインに従うことと、黒い字も4色の黒になるので小さな字を細くしすぎないことを書いている
- **確認** — 絵の解像度（dpi）、縦横比が違って切れる量、書き出した PDF のインク総量
- 刷り上がりの色のプレビューと、その画像（PNG）
- 設定・絵・プロファイルの自動保存（このブラウザの中だけ）
- 日本語・英語・韓国語の画面（ほかの shiki365 のツールと同じ切り替え）。印刷所と紙の名前は、印刷所の注文画面で同じものを探せるよう日本語のまま出し、英語・韓国語では印刷所名にローマ字を添える

## ICC プロファイルについて

色の変換には、利用者が選んだ `.icc`（Japan Color 2001 Coated など）を使う。**このツールはプロファイルを同梱しない**（Adobe のプロファイルは、アプリに同梱して配るのに別の契約が要るため）。

変換は相対的な色域維持＋黒点の補正（LittleCMS / Pillow の `RELATIVE_COLORIMETRIC` ＋ `BLACKPOINTCOMPENSATION` と同じ考え方）。B2A1 の表（lut8 / lut16）を読み、33×33×33 の RGB の表に焼いてから画像を変換する。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面と CSS |
| `favicon.svg` | ブラウザのタブに出るアイコン |
| `i18n.v1.js` | 言語の切り替え（ほかのツールと同じファイル） |
| `lang.en.v1.js` / `lang.ko.v1.js` | 英語・韓国語の辞書（キーは日本語の文） |
| `../doujin-printer-finder/papers.v1.js` | 印刷所の名前と紙の一覧（どの言語でも日本語のままのデータ、`i18n:off`）。**同人誌の印刷所さがしのファイルを読む** |
| `../doujin-printer-finder/printers.v1.js` | 判型、印刷所ごとの塗り足し・安全域・解像度・インク総量・注意書き・背幅の式。**同上** |
| `presets.v1.js` | 上の 2 つに「そのほか（数値を入力）」を足して `window.CoverPresets` にする |
| `icc.v1.js` | ICC プロファイルの読み込みと sRGB ⇔ CMYK の変換（UI に依存しない） |
| `cover.v1.js` | 寸法、ガイド、絵の当てはめ、CMYK とインク総量、PDF の書き出し（UI に依存しない。プレビューと書き出しで同じ関数） |
| `app.v1.js` | 画面の結線、自動保存（localStorage と IndexedDB）、書き出し |

印刷所のデータ（名前・紙・背幅の式）は、2026-11-06 から「同人誌の印刷所さがし」（`doujin-printer-finder`）と分け合っている。このツールは `../doujin-printer-finder/` のファイルを読むので、**公開するときは両方を出す**（手元で開くときも、2 つのフォルダを並べて置く）。データの取り出しと確かめの道具も、そちらの `_dev-local/printers/` に移した。

## 確かめたこと（v0.1、2026-10-30）

- `icc.v1.js` の変換を Pillow（`ImageCms.profileToProfile`、相対的な色域維持＋黒点の補正）と 8,832 色で比べた: 差は最大 1（0〜255）
- 実際の同人誌の表紙（見開き 5137×3624 px、背 2.8mm、権利表記なし）を通した PDF を、同じ絵から Pillow で作った PDF と画素ごとに比べた: 98.7% が同じ、差は最大 3。インク総量は 346% → 300%（Pillow のほうと同じ）。用紙の大きさと TrimBox は同じ
  - 背 2.7mm（絵 5137 px を 5136 px に縮める）では、縮小の補間の違いで線のふちに差が出る（平均 0.5）
- 背幅: 印刷所のページの計算フォームの JS をそのまま動かした答えと、10社（大陽出版・丸正インキ・ブロス・ねこのしっぽ・金沢印刷・ホープツーワン・サンライズ・緑陽社・関西美術印刷・PICO）のすべての紙 × 表紙 × 本文 8〜500 ページ（約31万通り）で一致。印刷所のページの計算例と、しまや出版の早見表（15種 × 243行）も一致
- 英語・韓国語: 辞書の検査で漏れ 0（181 件）。画面で全タブ・全印刷所を切り替えて `I18n.missing` が空、日本語が残るのは言語の切り替えの「日本語」だけ。375px で全タブはみ出しなし。ガイド画像のハングルが描けることも確認
